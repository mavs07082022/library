installation guide

download the zip file of the system in gdrive
extract it in C:\xampp\htdocs folder

download python at- https://www.python.org/downloads/windows/
click ctrl+f to search python 3.11
download windows installer (64-bit)
install it, check "add to path" then install

after installing python 3.11.9, double click the install_dependencies in C:\xampp\htdocs\lib\python folder

open cmd and type this command, cd C:\xampp\htdocs\lib\python
then install requirements, type this command, python -m pip install -r requirements.txt, then wait for installation finished

after installing double click run_nlp
then try the system in browser, http://localhost/lib/frontend/src/login.php
